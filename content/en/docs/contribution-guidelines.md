This site is open source and lives on [GitHub](https://github.com/joshuacarmack/tricitiesmesh.net). It's built with [Hugo](https://gohugo.io/) and the [Docsy](https://www.docsy.dev/) theme. Pages are written in Markdown.

## Small fixes

Spotted a typo or something out of date? Use the **Edit this page** link on any docs page. GitHub will walk you through forking the repo and opening a pull request.

## Bigger changes

1. Fork the repo and create a branch.
2. Run the site locally with `npm install` and then `hugo server`. See the [README](https://github.com/joshuacarmack/tricitiesmesh.net#running-locally) for details.
3. Content lives in `content/en/`. Node pages are in `content/en/nodes/<NAME>/index.md`.
4. Open a pull request. Every change is reviewed before it goes live.

## Reporting a problem

Not sure how to fix it yourself? [Open an issue](https://github.com/joshuacarmack/tricitiesmesh.net/issues/new) or email [contact@tricitiesmesh.net](mailto:contact@tricitiesmesh.net).
